ໃຜເປັນໃຜ

ແຕ່ລະຄົນໃຊ້ລິ້ງ ແລະລະຫັດຂອງຕົນເອງ. ສີຂອງປ້າຍບົດບາດນີ້ໃຊ້ເປັນຕົວຊີ້ທົ່ວຄູ່ມື.

ລູກຄ້າ

ສັ່ງຊື້ ແລະຕິດຕາມບິນຂອງຕົນເອງ ບໍ່ຕ້ອງມີລະຫັດ.

ໃຊ້: ລິ້ງລູກຄ້າ

ເຈົ້າຂອງຮ້ານ

ເຫັນ ແລະແກ້ໄດ້ທຸກຢ່າງ: ສິນຄ້າ ລາຄາ ຕັ້ງຄ່າ ລາຍງານ ລົບອໍເດີ.

ໃຊ້: ລິ້ງແອດມິນ + ລະຫັດເຈົ້າຂອງ

ພະນັກງານທົ່ວໄປ

ຜູ້ຊ່ວຍທີ່ຕ້ອງເຫັນອໍເດີທຸກກຸ່ມ (ເຊັ່ນ ຄົນຮັບໂທລະສັບ). ແກ້ຊື່-ທີ່ຢູ່ ແລະຮັບເງິນໄດ້ ແຕ່ແກ້ສິນຄ້າ ຕັ້ງຄ່າ ລາຍງານບໍ່ໄດ້. ບໍ່ຈຳເປັນຖ້າບໍ່ມີຜູ້ຊ່ວຍ.

ໃຊ້: ລິ້ງແອດມິນ + ລະຫັດພະນັກງານ (STAFF_PASSWORDS ຄົນລະລະຫັດ)

ຜູ້ຮັບຜິດຊອບກຸ່ມ

ລູກຄ້າ ສັ່ງຊື້ໃນມືຖື

ບໍ່ຕ້ອງສະໝັກ ບໍ່ຕ້ອງລົງແອັບ. ເປີດລິ້ງ ແລ້ວສັ່ງໄດ້ເລີຍ.

  1. ຕິດຕາມບິນ: ເມນູ "ບິນ & ອໍເດີຂອງຂ້ອຍ" ສະແດງສະຖານະ ສົ່ງແລ້ວ → ຮ້ານຮັບແລ້ວ → ກຳລັງຈັດສົ່ງ → ສຳເລັດ.ບິນເກັບໃນມືຖືເຄື່ອງນັ້ນ. ເຄື່ອງອື່ນຄົ້ນຫາດ້ວຍເລກອໍເດີ + ເບີໂທ.
  2. ມັດຈຳກະຕຸກ: ສິນຄ້າທີ່ມີມັດຈຳ (ເຊັ່ນ ນ້ຳ 18,9 ລິດ) ຈະຄິດມັດຈຳລວມໃນຍອດ. ມີກະຕຸກເກົ່າມາແລກ ເລືອກ "ມີກະຕຸກເກົ່າ" ຈະບໍ່ເສຍມັດຈຳ.
  3. ຈ່າຍເງິນ: ເກັບເງິນປາຍທາງ. ຖ້າຢາກໂອນ ຝ່າຍຮ້ານຈະທັກ WhatsApp ສົ່ງເລກບັນຊີໃຫ້ຫຼັງຮັບອໍເດີ.
  4. ພາສາ: ເມນູ ☰ ເລືອກ ລາວ / ไทย / EN. ຕິດຕັ້ງເປັນແອັບ: ເມນູ ☰ ກົດ "ຕິດຕັ້ງແອັບ".

    ແຖບ "ສະຕັອກ" ເຫັນສະເພາະສິນຄ້າຂອງກຸ່ມຕົນ. ໃສ່ຈຳນວນຄົງເຫຼືອຈິງ ຫຼືກົດ +10 / +50 / +100 ເມື່ອເຄື່ອງເຂົ້າ ແລ້ວກົດ 💾 ບັນທຶກ.ແກ້ສະເພາະຈຳນວນ ບໍ່ເຫັນ/ແກ້ລາຄາໄດ້. ລະບົບຕັດສະຕັອກເອງເມື່ອມີອໍເດີ ແລະຄືນເມື່ອຍົກເລີກ.

  • 7

ໜ້າແອດມິນບໍ່ເຫັນຂອງໃໝ່ / ປຸ່ມບໍ່ຂຶ້ນກົດ Ctrl+F5 (ມືຖື: ປິດແລ້ວເປີດໜ້າໃໝ່). ເບຣາເຊີອາດເກັບໜ້າເກົ່າໄວ້.
ລືມລະຫັດ ຫຼືຢາກປ່ຽນລະຫັດເຈົ້າຂອງປ່ຽນໄດ້ທີ່ Apps Script → Project Settings → Script properties (ADMIN_PASSWORD / STAFF_PASSWORDS / GROUP_PASSWORDS). ບໍ່ຕ້ອງ deploy ໃໝ່.
ເພີ່ມສິນຄ້າໃໝ່ ແລ້ວລູກຄ້າບໍ່ເຫັນກວດ 3 ຢ່າງ: ຕິກ ☑ "ສະແດງໃນຮ້ານ", ໃສ່ລາຄາ, ແລະກົດ 💾 ບັນທຶກສິນຄ້າທັງໝົດ. ແລ້ວ Ctrl+F5 ໜ້າລູກຄ້າ.
ອໍເດີບໍ່ຂຶ້ນໃຫ້ຜູ້ຮັບຜິດຊອບກຸ່ມກວດວ່າສິນຄ້າຖືກໃສ່ "ກຸ່ມຈັດສົ່ງ" ແລະຊື່ກຸ່ມຕົງກັບລະຫັດກຸ່ມ ເຊັ່ນ ນ້ຳແພັກ. ອໍເດີເກົ່າກ່ອນໃສ່ກຸ່ມ ຈະບໍ່ຂຶ້ນໃຫ້ກຸ່ມ (ເຈົ້າຂອງເຫັນຢູ່).
Telegram ບໍ່ແຈ້ງເຕືອນໃຫ້ເຈົ້າຂອງຣັນຟັງຊັນ testGroupNotify ໃນ Apps Script ແລ້ວເບິ່ງ log. ກວດວ່າບອດຢູ່ໃນກຸ່ມ ແລະ TELEGRAM_TOKEN ຖືກຕ້ອງ.
ລູກຄ້າຢາກໂອນເງິນຝ່າຍຮັບກົດ "ຢືນຢັນຮັບ" ແລ້ວ "💬 ແຈ້ງລູກຄ້າ" ຂໍ້ຄວາມຈະມີບັນຊີຂອງຝ່າຍນັ້ນ. ລູກຄ້າໂອນ ແລະສົ່ງສະລິບທາງແຊັດ ຝ່າຍນັ້ນກວດ ແລ້ວກົດ "ຮັບເງິນແລ້ວ".
ຕົວແທນຢາກເພີ່ມສະຕັອກ ຫຼືເບິ່ງຍອດຂາຍໃນແອດມິນຂອງຕົວແທນ ແຖບ ສະຕັອກ (ແກ້ຈຳນວນສິນຄ້າຂອງກຸ່ມຕົນ) ແລະແຖບ ສະຫຼຸບ (ຍອດຂາຍ ສະເພາະກຸ່ມຕົນ). ສິນຄ້າຕ້ອງຖືກໃສ່ "ກຸ່ມຈັດສົ່ງ" ໂດຍເຈົ້າຂອງ ຈຶ່ງຈະຂຶ້ນໃຫ້ກຸ່ມ.
ຕົວແທນຢາກເພີ່ມຜະລິດຕະພັນໃໝ່ / ແກ້ລາຄາເຮັດເອງບໍ່ໄດ້ ຕ້ອງແຈ້ງເຈົ້າຂອງ. ເຈົ້າຂອງເພີ່ມໃນແຖບ ສິນຄ້າ ແລະໃສ່ກຸ່ມ ແລ້ວຕົວແທນຈະເຫັນໃນແຖບ ສະຕັອກ.
ຢາກໃຫ້ຕົວແທນເຫັນ Google Sheet ບໍ?ບໍ່ຕ້ອງ. ຕົວແທນໃຊ້ແອດມິນດ້ວຍລະຫັດກຸ່ມທັງໝົດ. ການແຊຣ໌ Sheet ຈະເຮັດໃຫ້ເຫັນຂໍ້ມູນທຸກກຸ່ມ ແລະທຸກລູກຄ້າ.

ຄູ່ມືນີ້ສະແດງຕາມລະບົບທີ່ໃຊ້ງານຕອນນີ້ (ຂໍ້ມູນ: Google Sheet · ເວັບ: GitHub Pages · ຫຼັງບ້ານ: Google Apps Script). ຖ້າລະບົບປ່ຽນ ຄວນອັບເດດຄູ່ມື.
